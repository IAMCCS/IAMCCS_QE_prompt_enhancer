================================================================================
ADDITIONAL FEATURES
================================================================================

MAINTAIN CONSISTENCY (Boolean Toggle)
→ When enabled, adds " | Maintain the consistency" to the prompt
→ Helps maintain visual consistency across edits
→ Only works when a preset is selected

GET POSE IMAGE 3 (Boolean Toggle)
→ When enabled, adds " | Get the pose of image 3" to the prompt
→ Can work independently without selecting any preset
→ Useful for pose transfer operations

CLEAR SELECTION (Button)
→ Resets the prompt output to empty string
→ Clears search filter
→ Deselects all cards

SEARCH (Text Input)
→ Filter presets by label name
→ Real-time filtering as you type
→ Selected cards remain visible during search
